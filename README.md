# Hi, I'm Yurii 👋

Scientific computing researcher in London, sitting at the junction of **numerical
methods**, **quantitative finance** and **machine learning**. I like problems where
the answer is a number and there is a second, independent way to compute it — that
is how you find out whether the first way was right.

## 🔭 What I work on

- **High-performance computing** — sparse linear solvers, parallel decomposition,
  CFD. My MPhil at Cambridge was on massively parallel sparse solvers.
- **Quantitative finance** — options, hedging, risk. Everything simulated, every
  number checked against a closed form.
- **Machine learning** — training pipelines and evaluation, mostly on scientific
  imaging problems.

## 📦 Projects

| | what it is | the independent check |
|---|---|---|
| ⚡ [cuda-acceleration](https://github.com/statslink/cuda-acceleration) | CUDA finite-volume solver for the 2D compressible Euler equations, 10–18× over CPU | the serial solver, on the same benchmarks |
| 📉 [discrete-delta-hedging](https://github.com/statslink/discrete-delta-hedging) | how fast the error of a discrete delta hedge vanishes: like N^−1/2 | a one-step Taylor argument, derived on paper |
| 🎲 [stochastic-risk-modelling](https://github.com/statslink/stochastic-risk-modelling) | Cramér–Lundberg ruin probabilities by Monte Carlo | geometric-sum representation and Laplace inversion |
| 📊 [discrete-statistical-modelling](https://github.com/statslink/discrete-statistical-modelling) | fitting Poisson vs geometric models to a small sample | method of moments vs MLE, then χ² |
| 🔬 [cnn-focus](https://github.com/statslink/cnn-focus) | learning-based autofocus for 3D microscope image stacks | classification vs regression on the same stacks |

Each repository is small and self-contained: the code, a short write-up, and the
figures that back it.
